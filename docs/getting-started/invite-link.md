# Accept an Invite Link

If your admin emails an invite link (`/invite/[token]`), use this flow.

## What the invite link does

- Confirms the invitation is valid and not expired
- Shows the club name and invite email
- Lets you join directly after sign-in/sign-up

## Step-by-step

1. Open the invite link from your email.
2. Review the invite screen.
3. If you are not signed in:
   - Tap **Sign Up & Join Club** (or sign in from the link). Sign-up only asks for your email, a password (at least 8 characters), and your full name.
4. If you are already signed in:
   - Tap **Accept & Join Club**
5. If you don't have an emergency contact on file yet, a **Before you fly** step asks for an emergency contact name and phone — clubs need someone to call in an emergency.
6. You are sent into the app after acceptance.

*Screenshot: [Invite token page with Accept and Join button]*

## If the invite does not work

You may see:

- **Invalid Invitation**: token is wrong or already used
- **Invitation Expired**: admin needs to send a new invite
- **Already Accepted**: invite has already been used

:::tip
Invite links are the easiest way to onboard pilots because email and club are pre-linked.
:::
