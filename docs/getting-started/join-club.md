# Join an Existing Club

This guide covers joining a club from mobile or web.

## What you'll need

- Your club's **Club Key**
- Your club's **Club Password**
- An emergency contact name and phone, if you don't have one on file yet — joining a club is the **Before you fly** moment where Air Boss asks for it (clubs need someone to call in an emergency)

:::warning
Air Boss join flow uses club credentials, not club-name search.
:::

## Join on mobile

1. Complete account sign-up.
2. In the join step, enter:
   - **Club Key**
   - **Club Password**
3. Submit your profile.
4. Wait for admin approval if your club uses approval workflow.

*Screenshot: [Mobile club key and club password entry step]*

## Join on web

1. Go to **Join an existing club**.
2. Enter your **Club Key** and **Club Password**.
3. Submit.
4. If approved immediately, you enter the app.
5. If approval is required, you go to **Pending Approval**.

*Screenshot: [Web join-club form and pending approval confirmation]*

## If join fails

- Check for typing errors in club key/password.
- Ask your admin to confirm credentials were shared correctly.
- If you already submitted once, check **Pending Approval** before trying again.

## After approval

You can:

- View aircraft and schedules
- Create reservations
- Log flights
- Report squawks
- Upload and track required documents
