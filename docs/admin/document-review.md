# Document Review (Admin)

Use `/dashboard/document-review` to review member document uploads and provide feedback.

## What you can do

- Filter queue by member, club, document type, and date range
- Open file preview (image/PDF)
- Zoom, rotate, and navigate PDF pages
- Add public feedback comments
- Set expiration dates (when required)
- Approve or request changes

*Screenshot: [Document Review queue with filters and document preview panel]*

## Review workflow

1. Open **Document Review**.
2. Select a queued document.
3. Inspect file quality and details.
4. Add member-visible feedback (if needed).
5. Set expiration date when applicable.
6. Click **Approve** or **Request Changes**.

## Audit trail

The detail view keeps comment and review history for traceability.

:::tip
Use clear, action-oriented feedback so pilots can fix issues in one upload cycle.
:::
