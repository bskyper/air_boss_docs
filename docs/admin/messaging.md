# Messaging (Admin)

Use `/dashboard/flight-ops/messaging` to send club-wide broadcasts.

## Delivery channels

You can send to one or both:

- **Push notifications** (to active devices)
- **Comms feed** (persistent in-app timeline post)

## Send a broadcast

1. Open **Messaging**.
2. Choose channels (push, comms feed, or both).
3. Add optional title.
4. Enter message body.
5. Send broadcast.

*Screenshot: [Admin messaging page with push/feed toggles and message body]*

## What success looks like

- Push summary reports delivery counts
- Feed option posts directly to club comms timeline

:::warning
Confirm active club in the top bar before sending any broadcast.
:::
