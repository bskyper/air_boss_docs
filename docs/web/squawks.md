# Report and Track Squawks (Web)

Use **Squawks** to file aircraft issues, attach photos, and follow progress through resolution.

## What you'll need

- Active club selected
- Approved membership

## File a squawk

1. Open **Squawks**.
2. Select a **Tail number** from the dropdown. If the aircraft is not listed, type the tail number manually.
3. Choose a **Priority**: Low, Medium, or High.
4. Choose a **Category**: Mechanical, Electrical, Avionics, Interior, Exterior, or Other.
5. Enter a short **Summary** — one line that describes what is wrong.
6. Enter a full **Description** — include when you noticed it, flight conditions, and any relevant context.
7. Attach photos if you have them (see below).
8. Click **Submit**.

A confirmation appears: "Squawk filed. Admins will be notified."

*Screenshot: [New squawk form with tail, priority, category, summary, description, and attachment area]*

:::tip
Write the summary as a one-line problem statement. Put everything else — observations, conditions, flight phase — in the description.
:::

## Attach photos

1. Click the attachment area in the squawk form.
2. Select one or more image files (JPEG, PNG, and most common image formats are accepted).
3. Thumbnails appear below the selector. Click **×** on a thumbnail to remove it before submitting.
4. Photos are compressed automatically — no need to resize before uploading.

## Find squawks in the list

The squawk list is on the right side of the Squawks page.

### Filter by status

Click a status button to narrow the list:

- **All** — show every squawk
- **Open** — filed, waiting for review
- **In Progress** — actively being worked
- **Deferred** — noted, not immediately actioned
- **Pending Parts** — waiting on parts
- **Closed** — resolved

### Filter by aircraft

Click a tail number button below the status row to show only squawks for that aircraft.

### Search

Type in the search box to match by summary, description, tail number, pilot name, or category. Results update as you type.

*Screenshot: [Squawk list with status filter buttons, aircraft filter buttons, and search box]*

## Read a squawk row

Each row shows:

- **Summary** and clipped description
- Tail number badge
- Photo count badge and comment count badge
- Pilot name and submission date
- Status, priority, and category badges

Click any row to open the squawk detail page.

## Add a comment

1. Open the squawk detail page.
2. Type in the comment box at the bottom.
3. Click **Submit**.

Your comment is visible to all club members and admins.

To edit or delete a comment you wrote, click **Edit** or **Delete** next to it.

*Screenshot: [Squawk detail page with status section, photo gallery, and comment thread]*

## Track resolution

The status badge reflects where the issue stands. When a squawk is closed, a **Resolution** field appears on the detail page with the admin's notes.

| Status | Meaning |
|---|---|
| Open | Filed, waiting for admin review |
| In Progress | Actively being worked |
| Deferred | Noted but not immediately actioned |
| Pending Parts | Waiting on parts before repair |
| Closed | Resolved — see resolution notes |

:::warning
Only admins can change squawk status, add maintenance notes, or mark a squawk closed. Pilots can view all fields and add comments but cannot resolve a squawk.
:::

## Common issues

**No tail numbers in the dropdown**
Your club has no aircraft configured, or you do not have access. Contact your admin.

**Squawk you filed is not visible in the list**
Check the status filter — it may be set to a specific status. Click **All** to reset it. Also confirm you are in the correct club.

**Photos failed to attach**
Make sure the files are images (JPEG, PNG, or similar). Large files are compressed automatically but must be valid image formats.
