# Web App Overview

Air Boss web has two workspaces:

- **Pilot workspace** (`/app`)
- **Admin workspace** (`/dashboard`)

## Pilot workspace highlights

- Schedule and reservations
- My Flights and All Flights
- Aircraft reference
- Squawks
- Profile and Documents
- Notification preferences

## Admin workspace highlights

- Reservations and dispatch control
- Aircraft management
- Member approvals and user management
- Document compliance and document review
- Invitations
- Maintenance board
- Billing and subscription tools

## Access

Open [www.air-boss.club](https://www.air-boss.club) and sign in.
