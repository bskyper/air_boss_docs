# Manage Notification Preferences (Web)

Use `/app/settings/notifications` to control alert delivery for your active club.

## Open preferences

1. Go to **Settings > Notifications**.
2. Confirm your active club.

## Toggle categories

You can enable/disable push and/or email options for:

- Squawk notifications
- Grounded aircraft alerts
- Document notifications
- Reservation notifications
- Announcement notifications

*Screenshot: [Notification Preferences page with grouped switches]*

## Save behavior

Changes save as you toggle and sync with your account settings.

:::tip
Notification preferences are club-scoped and sync between web and mobile.
:::

## If you see "No active club selected"

Select an active club first, then return to notification settings.
