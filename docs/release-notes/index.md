## Changelog

## v2.4.1 — 2026-05-23

### New Features
- Added Instructor Network airport-aware discovery: profiles can be ranked by a verified reference airport and service-area coverage.
- Added personal default reference airports for Instructor Network search.
- Added on-demand airport verification and local caching so valid airport aliases can resolve to canonical airport records.

### Improvements
- Separated **Keyword search** filtering from **Reference airport** distance ranking so airport-code searches do not silently become the origin for distance labels.
- Added Instructor Network documentation covering reference airports, default search airports, verification, caching, and distance labels.

### Bug Fixes
- Aligned the Keyword search and Reference airport controls in the Instructor Network search panel.
